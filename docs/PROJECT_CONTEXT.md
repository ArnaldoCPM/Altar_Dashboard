# Nombre del proyecto

SGSA - Sistema de Gestão dos Servidores do Altar

# Objetivo

Sistema web para administrar los servidores del altar de una parroquia.

# Tecnologías

- HTML
- Tailwind CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Vercel

# Principios del proyecto

- Mantener el proyecto simple.
- Evitar frameworks innecesarios.
- Usar JavaScript modular (ES Modules).
- Una responsabilidad por archivo.
- Código reutilizable.
- Diseño responsive.
- Seguridad mediante Firestore Rules.
- Código fácil de mantener.

# Regla importante

Nunca modificar varias funcionalidades en una misma tarea.

Cada cambio debe tener un único objetivo.
